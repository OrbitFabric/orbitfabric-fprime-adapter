# OrbitFabric F Prime Adapter 0.1.3

**Published:** 2026-09-25 as [GitHub Release v0.1.3](https://github.com/OrbitFabric/orbitfabric-fprime-adapter/releases/tag/v0.1.3).

This patch establishes the post-migration release identity `github.com/OrbitFabric:orbitfabric/fprime@0.1.3` while preserving the previously accepted `0.1` adapter behavior.

## Changes

- Normalize active release metadata and Source Coordinate under the OrbitFabric Organization, with publisher `orbitfabric`.
- Preserve the existing `fpp_contract_projection` operation, Projection Profile semantics, Integration Result behavior and supported Core surfaces.
- Retain the exact F Prime v4.2.2 / FPP 3.2.0 target compatibility lane and the two public Reference Examples.
- Keep historical FAROTECH release descriptors, assets, locks, tags and accepted evidence unchanged.

## Acceptance boundary

Release publication and artifact availability are confirmed. The candidate integration checks retained in [PR #21](https://github.com/OrbitFabric/orbitfabric-fprime-adapter/pull/21) include unit tests, Ruff, package construction and an installed-product check using replayed pre-publication GitHub HTTP responses. These checks are not a substitute for an independent post-publication clean-environment end-to-end replay.

The generic Core-owned adapter lifecycle and integration contracts retain **candidate maturity**, irrespective of product-release publication. This patch does not claim a broader F Prime/FPP compatibility range, a new adapter operation or additional downstream-native acceptance.

See [Getting Started](../getting-started.md) and [Target Compatibility](../target-compatibility.md) for consumer guidance and supported downstream boundaries.
